# Repository Guidelines

## Git Commit Messages

- **Format:** Follow the Conventional Commits specification (e.g., `feat(earth): add 16K texture support`, `fix: resolve texture streaming bottleneck`) and use Markdown formatting where **applicable**.
- **Structure:** Write each paragraph in the commit message as a single continuous line.
- **Line Length:** Do not hard-wrap lines to conform to an 80-character line length limit.

## Workflow Rules

- **No Automatic Commits:** Do not create a git commit automatically after completing a task. Leave all changes staged or unstaged for manual review.
